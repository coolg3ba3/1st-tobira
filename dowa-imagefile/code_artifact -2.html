💡 パソコン起動時に自動でこの画面を開く設定方法（ご家族・管理者向け）

【Windowsの場合】

  1. このHTMLファイルをダブルクリックしてブラウザで開きます。
  2. キーボードの Windowsキー + R を押します。
  3. 「shell:startup」と入力してEnterを押します。
  4. 開いた「スタートアップ」フォルダの中に、このHTMLファイルの「ショートカット」を置きます。
  5. ブラウザの設定で、このページを「起動時に開くタブ」に登録しておくと確実です。

【フォルダ構成のご注意】

HTMLファイルと同じ階層に「ping-file」という名前のフォルダを作成し、その中に画像ファイル（02.png から 29.png）を保存してください。

※ ファイル名の番号は半角の2桁（02.png, 03.png ... 29.png）にしてください。
